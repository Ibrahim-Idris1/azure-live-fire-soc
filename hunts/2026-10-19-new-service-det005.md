## Hunt: New Service Installed — DET-005 Review

**Hunt date:** 2026-10-23

**Trigger:** DET-005, “New Service Installed,” on `vm-win-01`  
**Alert activity time:** 2026-10-19 14:32:57 UTC (15:32:57 UK local time)  
**Data source:** `Event` (Windows Service Control Manager, Event ID 7045)

### Hypothesis
The alert may have been generated by expected software installation or a controlled test rather than an unapproved service installation. I reviewed service-installation events on `vm-win-01` around the alert time and compared them with known environment changes.

### Scope
`vm-win-01`, Service Control Manager Event ID 7045, within 30 minutes before and after the alert activity time.

### Investigation step and query

#### 1. Find service installation events around the alert

This query returns Event ID 7045 records from the Service Control Manager on the affected Windows VM. Review the expanded event description for the complete service name, binary path, and service account.

```kusto
let alertTime = datetime(2026-10-19T14:32:57Z);
Event
| where TimeGenerated between ((alertTime - 30m) .. (alertTime + 30m))
| where Computer =~ "vm-win-01"
| where Source == "Service Control Manager"
| where EventID == 7045
| project TimeGenerated, Computer, Source, EventID, RenderedDescription
| order by TimeGenerated asc
```

### Findings
- The query returned two Event ID 7045 service-installation events in the search window.
- The first event, at `2026-10-19 14:32:57.364 UTC`, identifies the `LimaCharlie Service`. The analyst confirmed LimaCharlie is the environment's EDR tool and that this installation was expected.
- The second event, at `2026-10-19 15:02:11.192 UTC`, was identified by the analyst as a controlled test service installation. The screenshot truncates its service name and file name, so the full event details should be retained with the evidence.
- No evidence was provided that either of these two service installations was unauthorized.

### Conclusion
- [x] Alert explained by known EDR installation and controlled test activity
- [ ] Unauthorized service installation identified
- [ ] No other service installations occurred outside the queried window

Based on the event details visible in the query and the analyst's confirmation of the two activities, these events are expected and do not currently indicate suspicious service installation. This conclusion is limited to the two events returned in the investigated time window; it is not a claim that no other service installations occurred at other times.
